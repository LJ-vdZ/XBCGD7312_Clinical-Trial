To access the raw Blender project file containing all the 3D models, simply extract the Unity package.

Once extracted, you can open the Blender project file to inspect or edit the models as needed. This allows you to make any modifications and then re-export them to Unity or any other application of your choice.

The Blender version used for this project is 4.0. Make sure you have this version or a compatible one to ensure full compatibility with the project file.
